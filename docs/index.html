A Model Context Protocol Server

USCIS MCP Server

Primary-source immigration research for Claude — regulations, agency policy, and Board precedent, every answer carrying its citation.

Self-hosted  ·  No API key  ·  MIT License  ·  github.com/sgarcese/uscis-mcp

§ 1

The Problem It Answers

A language model's recollection of immigration law is a snapshot — and immigration law does not sit still. Processing times move monthly, the Policy Manual is revised without notice, and regulatory text changes under litigation. An attorney cannot cite a model's memory.

This server gives Claude live access to the primary sources themselves. When you ask about H-1B specialty-occupation requirements, the model reads the current 8 C.F.R. § 214.2(h) — not its training data. When you ask what the Board has held on moral turpitude, it searches the published precedent. Every response returns the source URL and the timestamp of retrieval, so the authority is always one click away.

§ 3

Provenance, Always

Every tool response is wrapped in the same envelope: the payload, the exact URL it came from, and when it was fetched. If an upstream source is briefly unreachable and a cached copy is served instead, the envelope says so — the model can reason about staleness rather than conceal it.

{
  "data":       { … },
  "source_url": "https://www.ecfr.gov/api/…",
  "fetched_at": "2026-07-17T19:16:36.341Z"
}

§ 5

Companion Skill: Attorney Research

The repository ships an Agent Skill, uscis-attorney-research, that layers structured legal-research workflows for immigration practitioners on top of the server's tools: RFE and NOID response research, client intake and case-strategy screening, precedent research for motions, appeals, and removal defense, policy verification, and pre-filing quality assurance.

Each workflow enforces the same discipline — fetch, don't recall; pinpoint citations with source URLs on every claim; explicit notes where a question exceeds the corpus. A bundled reference covers the I-290B motion and appeal framework in depth. Install it alongside the server in any client that supports Agent Skills.

§ 6

Installation

Runs entirely on your own machine — no account, no key, no client data leaving your network beyond the calls to the government sources themselves. Requires Node.js 18 or later.

git clone https://github.com/sgarcese/uscis-mcp
cd uscis-mcp && npm install && npm run build
npm run smoke   # verifies all 8 tools against live sources

Then register the server in Claude Desktop's claude_desktop_config.json:

{
  "mcpServers": {
    "uscis": {
      "command": "node",
      "args": ["/absolute/path/to/uscis-mcp/dist/index.js"]
    }
  }
}

Restart Claude Desktop and the eight tools appear automatically. For shared or remote deployments — HTTP transport, Docker, systemd, reverse proxy, authentication — see DEPLOYMENT.md.

Notice

Prototype · Unofficial · Not Legal Advice

This project is a prototype, intended to facilitate access to federal information sources for lawyers, advocates, researchers, and others. It is provided as-is, with no warranty of reliability, accuracy, or fitness for any purpose.

It is not affiliated with, endorsed by, or operated on behalf of USCIS or the Department of Justice. It retrieves publicly published government materials and one unofficial aggregator (processing times). Only precedential BIA decisions are covered; unpublished decisions are not systematically released by DOJ. Verify every authority at its source before relying on it in a filing. Software assists research; it does not practice law.

Requests for additional functionality are welcome — please open an issue on GitHub.
